Конфиденциальность игры «Ящики приливного дока»

Подготовлено 20 ноября 2026 года. Разработчик – Вердиханов Фейтулла Нейруллаевич. Контакт – verdikhanov01@bk.ru.

Игра сохраняет на устройстве открытые задания, звёзды, последовательность ходов и настройки. Учётная запись для игры не требуется. Android может резервировать данные приложения в зависимости от настроек устройства. Локальные данные можно удалить через очистку данных приложения в Android.

В игре используется Yandex Mobile Ads SDK для баннеров, межстраничной рекламы и добровольных роликов. SDK обрабатывает данные, связанные с доставкой и учётом рекламы, согласно политике Яндекса. [Политика Яндекса](https://yandex.ru/legal/confidential/)

Опция «Персональная реклама» в настройках по умолчанию выключена. Выбор можно изменить в любое время. Для игровых заданий подключение к сети не требуется.
