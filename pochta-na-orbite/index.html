Политика конфиденциальности игры «Почта на орбите»

Редакция от 21 ноября 2026 года. Игра для Android, пакет ru.orion.pochtanaorbite. Разработчик – Вердиханов Фейтулла Нейруллаевич. Контакт для вопросов о данных – verdikhanov01@bk.ru.

Игровые данные

Результаты рейсов и лучшие оценки по трассам сохраняются на устройстве. Регистрация не нужна. Игра не отправляет эти сохранения разработчику. Удалить локальные данные можно через очистку данных приложения в настройках Android. Системное резервное копирование зависит от настроек устройства.

Реклама

Игра использует Yandex Mobile Ads SDK для показа и учёта рекламы. При доступе к сети SDK может обрабатывать технические сведения об устройстве и приложении, сетевые сведения, рекламный идентификатор при его доступности, сведения о показах и взаимодействии с рекламой. Обработка описана в политике Яндекса. https://yandex.ru/legal/confidential/

Трассы, обучение и сохранённые результаты доступны без интернета. Для загрузки рекламы требуется подключение. Рекламным идентификатором можно управлять в настройках Android.
